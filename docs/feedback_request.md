> 코드: https://github.com/1230seongjun/stock-valuation-model (브랜치 `dev`)

## 1. 무엇을 만들었나

미국 상장 종목의 **현재 배수(PER·PBR·PSR·EV/EBITDA·P/FCF)가, 같은 날 비슷한 재무를 가진 회사들에 비해 높은지 낮은지**를 설명하는 스크리닝 도구입니다.

- **목표는 수익률 예측이 아닙니다.** "이 종목은 재무로 설명되는 수준보다 몇 % 비싸게/싸게 거래되고, 그 이유로 보이는 것은 무엇인가"를 서술합니다.
- 최종적으로는 웹·앱으로 공개하고, LLM(Claude)이 종목별 결과를 한국어로 설명하게 할 계획입니다.

### 용어 정의 (중요)
- **적정 배수**: 내재가치가 아니라, 같은 날 관측 가능한 재무·산업 특성으로 설명되는 *시장의 기준 배수*.
- **저평가/고평가**: 그 기준 대비 할인/프리미엄. 경제적 저평가나 초과수익을 뜻하지 않음.
- **괴리**: log(실제 배수 ÷ 적정 배수).

## 3. 모델

1. **기준일마다 따로 학습**: 그날의 종목 단면만 씁니다. 다른 날짜 데이터는 쓰지 않습니다. 시장 전체의 재평가가 모든 종목을 한꺼번에 "고평가"로 만들지 않게 하려는 설계입니다.
2. **타깃**: log(배수). 배수마다 범위 밖(적자, 0 근처 분모, 오류)은 제외합니다. 금융업은 PER·PBR만 씁니다.
3. **입력 변수**: 그날 백분위로 변환하고, 결측은 중앙값 + 결측 표시로 처리합니다.
   - 공통: ROE, 영업이익률, 매출성장률, 부채비율, 배당성향, 63일 변동성, 매출총이익률, 섹터 더미
   - 배수별 추가: PER(자본 규모, 3년 평균 ROE, 발생액) / PBR(순부채비율, 자본 규모, 3년 평균 ROE, 매출 규모, 이익 변동성) / PSR(자산회전율, 매출 규모, 세부 업종 더미) / EV/EBITDA(자산회전율) / P/FCF(FCF이익률, 현금 전환율, 매출 규모)
   - **주가에서 나온 값은 넣지 않습니다**(모멘텀, 52주 고점, 배당수익률, 시가총액). 주가 하락을 "원래 싸야 할 종목"으로 설명해 버리기 때문입니다.
4. **Ridge + 종목 단위 GroupKFold 5-fold out-of-fold**: 각 종목의 적정 배수는 그 종목을 뺀 모델로 계산합니다.
5. **종합 괴리** = 사용 가능한 배수 괴리의 평균 → 같은 날 순위 → **20%씩 다섯 구간 라벨**(매우 저평가 / 저평가 / 중립 / 고평가 / 매우 고평가).
6. **변수 채택 규칙**: Train과 Val 모두에서 out-of-fold R²가 +0.01 이상 오를 때만. 새 실험은 판정 기준을 먼저 정하고 시험합니다.

### 특수 처리
- **적자 기업**: PER이 없으므로 PSR·PBR(양수면 EV/EBITDA·P/FCF) 괴리를 **전 종목의 같은 배수 기준 괴리와 함께** 줄 세워 "적자 · 구간" 라벨을 붙입니다.
- **판단 보류**:
  - 빚 많은 적자 기업이 싼 쪽으로 나올 때(모델이 부도 위험을 못 봄)
  - 상장 1년 미만이면서 배수 하나로만 판단될 때
- **세부 라벨**: 가격에 반영된 초과 성장률 = (1+x)^10 = PER ÷ 중간 PER. 이 값과 최근 3년 실제 이익 성장률을 비교합니다.
- **경고 플래그**(라벨은 그대로): 최근 12개월 재무 단절(일회성 EPS), 재무 기준일 이후 주가 급변, 배수 하나로만 판단, 빚 많은 흑자 기업, 지속 할인·저성장, 가격·거래량 이상.
- **심리 지표**(설명용, 판정 무관): 공매도 비율 백분위, 위키피디아 관심도(같은 규모 그룹 내 백분위).
- **시장 전체 맥락**(설명용): S&P 500 CAPE를 10년 금리·물가·실업률(1990–2015 학습 고정)로 설명되는 수준과 비교합니다.

## 4. 결과

### 설명력 (out-of-fold R², 기준일 평균)

| 배수 | 섹터 중앙값 기준선 (Train/Val/Test) | 모델 (Train/Val/Test) | 오차 중앙값 / 상위 10% (Val) |
|---|---|---|---|
| PSR | 0.23 / 0.23 / 0.18 | 0.71 / 0.64 / 0.65 | 50% / 186% |
| PBR | 0.13 / 0.19 / 0.11 | 0.51 / 0.52 / 0.54 | 41% / 151% |
| PER | 0.08 / 0.18 / 0.17 | 0.39 / 0.44 / 0.36 | 38% / 137% |
| EV/EBITDA | 0.13 / 0.13 / 0.18 | 0.25 / 0.25 / 0.25 | 37% / 139% |
| P/FCF | 0.01 / 0.08 / 0.05 | 0.27 / 0.29 / 0.24 | 49% / 180% |

- 공매도·관심도를 입력으로 더하면 R² +0.01–0.04입니다(채택 안 함).
- 2년 뒤 실제 실적을 알아도 +0.03에 그쳤습니다. 재무로 설명하는 일은 한계에 가깝다고 봅니다.

### 안정성
- 직전 분기와 종합 괴리 순위상관 0.84–0.89. 양 끝 사이 직접 반전 0.1–0.3%.
- 괴리 계산 방식(평균/중앙값/가중/표준화)을 바꿔도 라벨 93–95%가 동일합니다.
- 양 끝 라벨 종목은 배수의 98%가 같은 방향을 가리킵니다.

### 수익률과의 관계 (모두 탐색적, Newey-West + FDR)
| 시험 | 결과 |
|---|---|
| 재무 지표 11개로 수익률 예측 (초기 버전) | FDR 후 0/60 → 중단 |
| 적정가 괴리 → 이후 1·3·6·12개월 수익률 | 13/96 유의, 그러나 **대형주 0/24**. 유의한 칸은 중소형주·Val 12개월에 몰림 → 생존 편향으로 해석 |
| 심리 신호 5종 → 이후 수익률 | 대형주에서 실질적으로 모두 기각 |

### 알려진 쏠림
- **소형주는 저평가, 대형주는 고평가 쪽으로** 쏠립니다. 규모 변수로 소형주 할인을 빼지 못해(계수가 음수, 분모 효과) 괴리에 남겨 두었습니다.
- AAPL·COST·NVDA처럼 프리미엄을 받는 기업은 늘 "고평가"로 나옵니다.
- "매우 저평가" 상위에 흑자 전환·일회성 손익 종목이 많습니다.

## 5. 이미 시도하고 기각한 것 (중복 제안을 피하려고 적습니다)

- **모델 구조**: XGBoost(과적합), 섹터별 계수, 섹터 내 백분위 타깃, 표준화 잔차, 선형·2차 보정, 자기 과거 대비 괴리, 플래그 기반 신뢰도 점수
- **변수**: 위험·유동성(Amihud는 시가총액 누수), SEC 조정 이익 PER, R&D·SBC·Capex(SBC는 주가를 따라감), 인수·주식 수 변화, 회사채 순발행, 사업 설명 텍스트 군집, 성장률 크기 변수(극단 성장 반영 확인용), 매출 베타
- **심리**: 공매도·관심도·내부자 거래(입력으로는 2년 전 배수 통제 후 기준 미달), 미시간 소비자심리·신용융자·풋콜·VIX·정책 불확실성(시장 맥락 모델에서도 기각)
- **빚 많은 적자 기업**: 순부채 변수, EV/매출로 해결 시도 → 실패해서 규칙(판단 보류)으로 처리

## 6. 스스로 의심하는 약점

1. **Val을 여러 번 썼습니다.** 변수 선택에 반복 사용해서 Val 성능은 편향된 추정치입니다.
2. **현재 분류를 과거에 소급**했습니다(GICS 섹터·세부 업종, 중소형주 구성 종목). 생존 편향과 분류 누수가 있습니다.
3. **공시 시점이 고정 지연 가정**입니다(표본상 10-Q 99.7%가 45일 안, 10-K 99.4%가 75일 안).
4. **백분위 변환**으로 극단값 정보를 버립니다(극단 성장 실험에서는 문제없었음).
5. **ROE·자산회전율 등의 분모 효과**: 배수 식 자체 때문에 생기는 관계가 설명 요인에 섞여 있습니다.
6. **괴리 = 모델이 못 본 모든 것**: 브랜드, 미래 기대, 사건, 데이터 오류가 구분되지 않습니다.
7. 라벨이 **같은 날 상대 순위**라서, 시장 전체가 비쌀 때도 20%는 "매우 저평가"입니다.

## 7. 특히 듣고 싶은 피드백

1. **방법론의 결함**: 기준일별 횡단면 Ridge + out-of-fold 구조, 백분위 변환, Train/Val/Test 운용에서 놓친 누수나 편향이 있나요?
2. **"설명 도구"로서의 가치**: 수익률 예측력이 없는 상대 밸류에이션 도구가 일반 사용자에게 쓸모가 있으려면 무엇을 어떻게 보여줘야 할까요? 오해를 막으려면 무엇을 꼭 표시해야 하나요?
3. **라벨 설계**: 상대 순위 다섯 구간, 소형주 할인을 괴리에 남겨 둔 결정, 적자 기업을 전체 종목과 같은 잣대로 비교하는 방식이 타당한가요?
4. **아직 안 써 본 무료 데이터**: 배수의 남은 50–75%를 설명할 만한 것이 있을까요? (조건: 과거 시점별 값이 있어야 하고, 주가가 섞이지 않아야 함)
5. **평가 지표**: R² 말고 이 도구의 "쓸모"를 측정할 방법은 무엇일까요?
6. **LLM 설명의 안전장치**: 숫자 검수, 금지 표현(예측·인과), 필수 언급(경계, 일회성, 재무 위험) 외에 무엇이 필요할까요?
7. **웹·앱으로 낼 때의 위험**: 법적·윤리적(투자 권유로 오해 등)·기술적 위험은 무엇인가요?
