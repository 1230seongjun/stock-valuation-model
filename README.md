# 적정 밸류에이션 스크리닝 (Stock_Prediction)

미국 상장 종목의 **현재 밸류에이션 배수가, 같은 시점 비슷한 재무를 가진 회사들에 비해 높은지 낮은지**를 설명하는 도구입니다.

- 기준일마다 그 시점의 종목들로, 재무 지표가 배수(PER, PBR, PSR, EV/EBITDA, P/FCF)를 얼마나 설명하는지 학습합니다.
- 실제 배수를 모델이 재무로 설명하는 **기준 배수**와 비교해 **저평가 / 중립 / 고평가**를 붙입니다.
- 판단마다 모델상 설명 요인, 가격에 반영된 성장률, 경고 플래그가 함께 나옵니다.

```
AAPL 2026-09-30: 고평가 · 요구 성장 ≈ 과거 성장
PER 38.6배 (적정 20.4배, +89%) — 적정 PER을 높인 요인 섹터 +54%, 3년 평균 ROE +14% / 낮춘 요인 ROE -36%(분모 효과), 배당성향 -14%
주가에 반영된 기대: 앞으로 10년간 이익이 중간 종목보다 매년 약 7% 더 늘어야 현재 PER이 설명됨 (최근 3년 이익 성장률 연 +14%, 중간 종목 +6%)
```

> **"적정 배수"는 내재가치가 아니라**, 같은 시점의 관측 가능한 재무·산업 특성으로 설명되는 시장의 기준 배수입니다. **"저평가"는 모델 기준 할인**이지, 경제적 저평가나 앞으로의 초과수익을 뜻하지 않습니다.
>
> **수익률 예측 모델이 아닙니다.** 괴리와 이후 수익률의 관계는 따로 검정했고, 생존 편향이 거의 없는 대형주에서는 유의하지 않았습니다(FDR 보정 후 0/24, [아래](#싸다는-판단이-이후-수익률로-이어졌나)).

                              종목을 5개 그룹으로 나눠 번갈아 제외하고 예측 (out-of-fold)
                                                     │
                     ┌───────────────────────────────┼───────────────────────────────┐
                     ▼                               ▼                               ▼

## 결과 읽는 법

### 괴리와 라벨

- **배수별 괴리** = 실제 배수 ÷ 기준 배수 − 1. 음수면 할인, 양수면 프리미엄. 목표가가 아니라 **배수의 차이**입니다.
- **종합 괴리** = 사용할 수 있는 배수 괴리(log)의 단순 평균. 적자 종목은 계산하지 않습니다.
- **라벨**은 같은 날짜 전체 종목을 종합 괴리로 줄 세워 붙입니다.

| 라벨 | 뜻 |
|---|---|
| 저평가 / 고평가 | 종합 괴리가 가장 낮은 / 높은 20% |
| 중립 | 나머지 60% |
| 판단 보류(적자) | 최근 분기 EPS·12개월 EPS·ROE 중 하나라도 음수 |
| 데이터 부족 | 계산할 배수가 없음 |

- **한 배수의 괴리 수십 %는 오차와 구분되지 않습니다**(오차 중앙값 37~50%). 여러 배수를 평균한 종합 괴리의 **양 끝 20%**에 들어야 의미를 둡니다.
- **일치도**(`agree`): 몇 개 배수가 종합 괴리와 같은 방향인지. 5개 배수는 같은 재무제표와 주가를 공유하므로 독립적인 5표는 아닙니다.
- **금융업**(모기지 리츠 포함)은 PER과 PBR만 씁니다. 매출·EBITDA·FCF의 뜻이 다른 업종과 달라서입니다.

### 세부 라벨: 가격이 요구하는 성장 vs 과거 성장

모든 라벨을 **가격에 반영된 초과 성장**과 **최근 3년 실제 초과 성장**(둘 다 같은 날 중간 종목 대비)의 비교로 한 번 더 나눕니다. 어느 쪽이 맞을지는 판단하지 않습니다.

| 세부 라벨 | 뜻 |
|---|---|
| 과거 성장 > 요구 성장 | 가격이 요구하는 성장이 지난 3년 실적보다 2%p 이상 낮음 |
| 요구 성장 > 과거 성장 | 가격이 지난 3년보다 2%p 이상 높은 성장을 요구함 |
| 요구 성장 ≈ 과거 성장 | 차이가 ±2%p 안 (`config.LABEL_DETAIL_BAND`) |
| 흑자 전환 | 3년 전 적자, 지금 흑자 (성장률 정의 불가) |
| 성장 이력 없음 | 지금 적자이거나 이력이 3년 미만 |

- 과거 성장 = 12개월 EPS의 3년 연평균 성장률. EPS가 없는 은행은 순이익(ROE × 자본)으로 대신합니다.
- **"(일회성 손익 가능)"**: 재무 단절 플래그가 있음. **"(기저 효과 가능)"**: 3년 성장률이 연 100% 초과(`config.BASE_EFFECT_CAGR`).
- 요구 성장의 기간(10년)을 5년·15년으로 바꾸면 세부 라벨의 89~94%가 같고, 경계 종목은 바뀝니다.

### 플래그 (라벨은 바꾸지 않는 경고)

| 플래그 | 조건 |
|---|---|
| 최근 12개월 재무 단절 | 최근 4분기 안에 분기 EPS가 평소(직전 8분기 중앙값)와 전년 같은 분기 **둘 다**의 3배 초과·1/3 미만, 또는 주당매출이 1.5배 넘게 급변 |
| 재무 기준일 이후 주가 급변 | 마지막 재무 분기 말 이후 주가 −33% 이하 또는 +49% 이상 |
| 한 가지 배수로만 판단 | 저평가·고평가인데 계산된 배수가 1개 |
| 지속 할인·저성장 경고 | 4개 시점 연속 저평가 + 매출성장률 섹터 하위 40% (밸류트랩 검증 규칙은 아님) |
| 단기 가격·거래량 이상 | 5거래일 ±15% + 거래량이 63일 평균보다 3표준편차 이상 |
| 저평가→고평가 전환 | 직전 시점 대비 라벨 반전, 원인(주가/실적) 분류 |

플래그가 붙은 종목은 큰 오차가 나올 확률이 1.5~2배 높습니다([어디서 크게 틀리나](#어디서-크게-틀리나)).

### 설명 요인과 "(분모 효과)"

"적정 PER을 높인 요인 섹터 +54%"는 **모델이 계산한 기여**이지 인과관계가 아닙니다. 일부 요인은 **배수를 계산하는 식 자체 때문에** 기준 배수를 움직여 "(분모 효과)"가 붙습니다.

| 배수 | 요인 | 식 |
|---|---|---|
| PER | ROE | PER = PBR ÷ ROE |
| PBR | 자본 규모 | 자본이 분모 |
| PSR | 자산회전율, 매출 규모 | 매출이 분모 |
| EV/EBITDA | 자산회전율 | EV/EBITDA = (EV ÷ 자산) ÷ (자산회전율 × EBITDA 마진) |
| P/FCF | FCF이익률, 현금 전환율, 매출 규모 | P/FCF = PSR ÷ FCF이익률 |

### 참고 열

- **반영된 기대 성장률**(`implied_excess_growth`): (1 + x)^10 = PER ÷ 중간 종목 PER. 할인율이 같고 10년 뒤 중간 PER로 돌아간다는 가정의 **단순한 상대 지표**이지 DCF가 아닙니다. 주가로 계산한 값이라 모델 입력으로 쓰지 않습니다.
- **정규화 PER**: 주가 ÷ (최근 12분기 평균 EPS × 4). 일회성 분기의 무게를 줄인 참고용이며, 재무 단절 종목에서도 PER보다 낫지 않아 종합 판단에는 넣지 않습니다.
- **sector_valuation_rank**: 모델 없이 섹터 안에서 비교한 순위. **quality_score**, **momentum_score**: 섹터 내 백분위 평균.

## 모델

### 타깃

**log(배수)**를 설명하고, 기준 배수 = exp(예측값), 괴리 = log(실제 ÷ 기준)입니다.

| 배수 | 제외 범위 | 비고 |
|---|---|---|
| PER | 1 미만, 100 초과, 적자 | |
| PBR | 0.1 미만, 20 초과 | |
| PSR | 0.05 미만, 40 초과 | 금융업 제외 |
| EV/EBITDA | 1 미만, 60 초과 | 금융업 제외 |
| P/FCF | 1 미만, 100 초과 | 금융업 제외 |
| 정규화 PER | 1 미만, 100 초과 | 참고용 |

Finnhub의 배수는 분기 말 주가 기준이라 스냅샷 날짜의 미수정 종가로 다시 계산합니다(EV/EBITDA는 시가총액 부분만). `verify-multiples`로 yfinance 현재 값과 비교할 수 있습니다(예: AAPL PER 보정 38.4 vs yfinance 38.9).

### 입력 변수

| 구분 | 변수 |
|---|---|
| 모든 배수 공통 | ROE, 영업이익률, 매출성장률, 부채비율, 배당성향, 63일 변동성, 매출총이익률, 섹터 |
| PER에 추가 | 자본 규모, 3년 평균 ROE |
| PBR에 추가 | 순부채비율, 자본 규모, 3년 평균 ROE, 매출 규모, 이익 변동성 |
| PSR에 추가 | 자산회전율, 매출 규모, 세부 업종 |
| EV/EBITDA에 추가 | 자산회전율 |
| P/FCF에 추가 | FCF이익률, 이익의 현금 전환율, 매출 규모 |

- **변수는 기준일마다 백분위로 바꿔 넣습니다.** 모델은 절대 수준이 아니라 같은 날 기업 중 상대적 위치를 봅니다. 값이 없으면 그날 중앙값으로 채우고 결측 표시 변수를 함께 넣습니다.
- **주가에서 나온 값은 넣지 않습니다**(모멘텀, 52주 고점 대비, 배당수익률, 시가총액). 주가 하락을 "원래 싸야 할 종목"으로 설명해 버리기 때문입니다. 63일 변동성만 위험 대용으로 예외입니다.
- **애널리스트 전망치도 넣지 않습니다.** 과거 시점별 값을 무료로 구할 수 없고, 넣으면 시장의 기대를 입력에 다시 넣는 셈입니다.

### 학습

- **기준일마다 따로 학습합니다.** 92개 기준일마다 그날의 종목으로 Ridge를 새로 적합합니다. 다른 날짜의 데이터는 쓰지 않습니다.
- **out-of-fold**: 종목을 5개 그룹으로 나눠, 각 그룹의 기준 배수는 그 그룹을 뺀 종목으로 학습한 모델로 계산합니다. 규제 강도(alpha, 0.01~1000)도 학습 그룹 안에서 고릅니다.
- **왜 Ridge인가**: 계수를 읽을 수 있어야 하고 변수끼리 상관이 큽니다. XGBoost(깊이 2)는 Train만 좋아지고 Val은 같았습니다(과적합).
- **Train / Val / Test의 뜻**: "과거 모델을 미래에 적용"하는 검증이 아니라, **Train·Val만 보고 정한 설계가 다른 시대(Test)의 단면에서도 유지되는지** 보는 용도입니다. Val은 변수 선택에 여러 번 썼으므로 편향 없는 추정치가 아닙니다.
- **미래 데이터 차단**: 재무는 분기 말 45일 뒤(회계연도 4분기는 75일 뒤), 주가는 당일까지. 규칙은 모두 `src/features.py`에 있고 테스트로 확인합니다.

### 변수 선택 규칙

- **채택**: `compare-features`에서 **Train과 Val R²를 모두 +0.01 이상** 올릴 때만. 모든 배수에서 올리면 공통 변수, 일부에서만 올리면 그 배수에만 넣습니다.
- **제외**: 공통 변수는 **원래 구성에서 함께 뺐을 때** 다섯 배수 모두 0.01 넘게 떨어지지 않으면 뺍니다(겹치는 변수는 하나씩 빼면 모두 기준 아래로 보이기 때문).
- **기준값에 민감합니다.** 0.005로 낮추면 후보 10개가 더 들어오고, 0.02로 높이면 배수별 추가 변수 14개 중 9개가 빠집니다.
- 시도하고 기각한 변수와 수치는 `src/config.py` 주석에 있습니다.

## 결과

2026-09-30 기준, 1,261종목, 92개 시점. 모든 수치는 out-of-fold입니다.

> **현재 버전은 기준선으로 동결했습니다**(태그 `baseline-2026-09-30`). 과거 재무 변수, 성장 추세, 섹터 내 상대 순위, 종합 방식, 보정, 신뢰도 점수까지 시험했지만 개선이 없었습니다. 같은 종류의 변수를 더 만들거나 기준값을 조정하는 대신, **새로운 종류의 정보**(시점별 컨센서스, 어닝 서프라이즈, 사건 정보 등)를 확보했을 때만 성능 실험을 다시 시작합니다.

### 설명력

R²는 **현재 배수의 종목 간 차이 중 재무 변수로 설명되는 비율**이지 미래 예측력이 아닙니다.

| 배수 | 섹터 중앙값 기준선<br>Train / Val / Test | 모델<br>Train / Val / Test | 순위 상관<br>(Val) | 오차 중앙값 / 상위 10%<br>(Val) |
|---|---|---|---|---|
| PSR | 0.23 / 0.23 / 0.18 | **0.71 / 0.64 / 0.65** | 0.81 | 50% / 186% |
| PBR | 0.13 / 0.19 / 0.11 | **0.51 / 0.52 / 0.54** | 0.73 | 41% / 151% |
| PER | 0.08 / 0.18 / 0.17 | **0.38 / 0.43 / 0.34** | 0.65 | 37% / 141% |
| EV/EBITDA | 0.13 / 0.13 / 0.18 | **0.25 / 0.25 / 0.25** | 0.48 | 37% / 139% |
| P/FCF | 0.01 / 0.08 / 0.05 | **0.27 / 0.29 / 0.24** | 0.54 | 49% / 180% |

- 다섯 배수 모두 기준선보다 높고, 시대가 바뀌어도 크게 떨어지지 않습니다. 섹터 × 규모 중앙값도 모델을 대신하지 못합니다.
- **분모 효과를 빼도 기준선보다 높습니다.** 분모 효과 요인을 모두 빼면 R²가 PER 0.43 → 0.31, P/FCF 0.29 → 0.20(Val)으로 크게 줄지만, 다섯 배수 모두 여전히 기준선 위입니다.
- **라벨은 분기마다 크게 흔들리지 않습니다.** 직전 분기와의 순위 상관 0.84~0.89, 라벨이 바뀌는 비율 18~21%, 저평가↔고평가 직접 반전 0.1~0.3%.
- **계산 방식에 강건합니다.** 종합 괴리를 평균 대신 중앙값, 설명력 가중, 표준화 잔차로 바꿔도 라벨의 93~95%가 같습니다.
- **극단 라벨은 배수 간에 일관됩니다.** 저평가·고평가 종목은 배수의 98%가 같은 방향이고, 5개 모두 같은 방향이 91~93%입니다(중립 79%).

### 모델이 기대는 것

변수 그룹을 통째로 뺐을 때 잃는 Val R²:

| 그룹 | PER | PBR | PSR | EV/EBITDA | P/FCF |
|---|---|---|---|---|---|
| 수익성 (ROE, 이익률, 3년 평균 ROE) | **0.140** | **0.117** | 0.073 | 0.026 | 0.033 |
| 성장 (매출성장률) | 0.008 | 0.007 | 0.007 | 0.007 | 0.011 |
| 배수별 구조 변수 (PER·PBR 자본 규모, PSR·EV/EBITDA 자산회전율, P/FCF 현금) | 0.025 | 0.060 | 0.067 | 0.011 | **0.084** |

- 모델은 대부분 **수익성**과 배수별 **구조 변수**에 기댑니다. **과거 성장 정보는 거의 기여하지 않습니다.**
- 성장의 방향(매출성장 가속도, 12개월 매출성장률, 이익률 변화)을 넣어도 ±0.005 이내였고, 잔차를 성장 변수 9개로 회귀해도 R²가 약 0이었습니다(Train·Test). 현재 변수 안에서는 과거 성장이 설명하지 못한 부분을 더 설명하지 못합니다. **남은 차이가 무엇인지**(미래 기대, 브랜드, 유동성, 회계 특성, 사건, 데이터 오류)는 구분하지 못했습니다.
- 후보 30여 개를 한꺼번에 넣으면 +0.02~0.06 오르지만 채택하지 않았습니다. Val을 이미 여러 번 썼기 때문에, 묶음을 바꿔 가며 작은 개선을 찾으면 Val에 맞춘 선택이 되기 쉽습니다.
- **표본 크기는 주된 한계가 아닙니다.** 종목을 75% → 100%로 늘릴 때 Val R²가 +0.002~0.019 오르는 데 그칩니다(학습 곡선이 평평해지는 구간).

### 어디서 크게 틀리나

- **평균적인 치우침은 작고, 개별 종목의 흩어짐이 큽니다.** 예측값 10분위 어디서나 평균 잔차는 대부분 ±0.05(log)이지만, 오차 상위 10%는 0.8~1.1입니다. 실제 배수가 기준의 2.2~3배이거나 그 반대인 종목이 **어느 구간에나** 있습니다.
- **보정은 효과가 없습니다.** 선형 보정의 기울기가 0.97~0.99였고, 2차 보정은 PSR 양 끝의 치우침(약 −0.1~−0.2)만 줄이고 평균 오차는 0.002 이하로 줄여 넣지 않았습니다. "선형 형태의 오지정이 오차의 주된 원인이라는 증거는 약하다"까지만 말할 수 있습니다.
- **큰 오차(|잔차| > 0.8)는 한 원인으로 모이지 않습니다.** 큰 오차는 Val 15%, Test 14%입니다. 기준(Val·Test 모두 1.5배 이상, 행의 5% 이상)은 미리 정했습니다.

| 요인 | 큰 오차 확률 배율<br>(Val / Test) | 행 비중 |
|---|---|---|
| 주당매출 급변 (분사·합병·데이터) | **1.8 / 2.1** | 6% |
| 현재 적자 (라벨은 판단 보류) | **1.9 / 2.1** | 11% |
| ROE 하위 20% | **1.5 / 1.6** | 15% |
| 흑자 전환 | 1.5 / 1.5 (경계) | 11% |
| 매출성장 상위 20% | 1.5 / 1.5 (경계) | 18% |
| 쓸 수 있는 배수 1~2개 | 1.5 / 1.5 (경계) | 20% |
| 일회성 EPS 분기 | 1.4 / 1.5 | 30% |
| 소형주 | 1.2 / 1.2 | 44% |
| 커뮤니케이션 서비스 / 유틸리티 | 2.0 / 2.0, 0.3 / 0.3 | 3%, 5% |

- 플래그가 하나라도 있는 행은 전체의 49%이고, 큰 오차 중에서는 61%입니다. **큰 오차의 39%에는 어떤 플래그도 없습니다.**
- **플래그로 "신뢰도"를 매기는 것도 시험했지만 기준에 못 미쳤습니다.** Train에서 플래그·업종으로 점수를 만들어 Val·Test에 적용했더니(큰 오차는 out-of-fold 잔차 기준), "신뢰도 낮음" 그룹의 큰 오차 비율이 나머지의 1.7~2.0배(AUC 0.62)였습니다. 미리 정한 기준(2배 이상)을 넘지 못해 신뢰도 표시는 넣지 않고, 기존 플래그를 경고로만 둡니다. Train에서는 2.4배였지만 학습 없는 단순 규칙도 똑같이 떨어져, 하락 원인은 과적합보다 시기 차이(Val·Test는 큰 오차 자체가 많음)로 봅니다.
- **극단값은 오래 갑니다.** 가장 싼 5%는 다음 분기에도 93%가, 가장 비싼 5%는 95%가 같은 구간에 남습니다.

### "싸다"는 판단이 이후 수익률로 이어졌나

모델 설정과 무관한 **탐색적 검정**입니다. 날짜마다 할인 순위와 이후 1·3·6·12개월 수익률의 순위 상관(IC)과 양 끝 20%의 수익률 차이를 보고, Newey-West와 96칸 전체 FDR 보정을 적용했습니다. 거래비용은 고려하지 않았습니다.

**결과: 13/96 유의** — 전체 3/24, **대형 0/24**, 중형 4/24, 소형 6/24.

| 그룹 | 구간 | 1개월 IC / 보정 p | 12개월 IC / 스프레드 / 보정 p |
|---|---|---|---|
| 대형 | Val | +0.002 / 0.98 | −0.000 / +1.0% / 1.00 |
| 중형 | Val | +0.028 / 0.69 | **+0.130 / +11.9% / 0.005** |
| 소형 | Train | **+0.050 / 0.001** | +0.047 / +3.3% / 0.06 |
| 소형 | Val | +0.035 / 0.55 | **+0.124 / +15.0% / 0.002** |
| 전체 | Test | −0.003 / 0.96 | +0.040 / +5.3% / 0.37 |

- **수익률 예측력으로 읽으면 안 됩니다.** 중소형주 목록은 현재 구성 종목이라 과거에 망한 종목이 빠져 있고(생존 편향), 유의한 칸은 중소형주에 몰려 있습니다. 생존 편향이 거의 없는 대형주는 0/24입니다.
- 소형주 효과는 단기 반전(최근 1·3개월 수익률)을 통제해도 그대로였습니다. 생존 편향 쪽으로 해석하지만, 상장폐지 데이터 없이는 구분할 수 없습니다.
- Val 12개월은 독립 관측이 4개 정도이고(2020년 이후 중소형주 반등), FDR 경계의 소형주 칸은 설정을 바꿀 때마다 13~17칸 사이에서 오갑니다.

## 한계

**모델이 보지 못하는 것은 모두 괴리에 들어갑니다.** 브랜드·해자·경영진, 미래 성장과 애널리스트 기대, 유동성과 투자 심리. 그래서 COST, WMT, AAPL처럼 프리미엄을 받는 기업이 늘 "고평가"로 나옵니다. 이런 종목은 세부 라벨과 반영된 기대 성장률을 보세요.

**PER의 ROE 계수(−0.31)는 해석이 섞여 있습니다.** PER = PBR ÷ ROE라는 식 구조 때문에, "시장이 높은 수익성이 식을 것으로 본다"는 뜻으로 읽을 수 없습니다(ROA도 같은 식 구조라 구분되지 않음).

**섹터가 넓습니다.** 세부 업종은 PSR에만 들어갔고(다른 배수는 과거 구간에서 오히려 나빠짐), 섹터와 세부 업종 모두 현재 분류를 과거에 소급합니다.

**12개월 합산 재무는 일회성 항목에 약합니다.** 예: 2026-09-29 HON이 일회성 이익(분기 EPS 17.8, 평소 약 2.4)과 주당매출 급변 때문에 저평가 1위였습니다. 재무 단절 플래그를 확인하세요.

**재무를 아는 시점은 고정 지연 가정입니다.** Finnhub에 공시일이 없어 10-Q는 45일, 10-K(회계연도 4분기)는 75일을 씁니다. 표본 점검에서 10-Q의 99.7%가 45일 안, 10-K의 99.4%가 75일 안에 공시됐습니다. 회계연도 말은 종목마다 확인합니다(AAPL 9월, WMT 1월, 전체의 23%가 12월이 아님).

**생존 편향.** 현재 구성 종목을 과거에 소급하므로 상장폐지 종목이 빠져 있습니다. 설명력에는 영향이 작지만 수익률 검정은 부풀려질 수 있습니다. 규모 그룹도 오늘 기준이라 보고서 분리에만 씁니다.
